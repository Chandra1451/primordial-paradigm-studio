How an essay page should read

Placeholder text. This page tests the essay layout; it is not an essay. Every paragraph below describes the page you are looking at.

The text column holds about sixty-five characters per line. Longer lines make the eye work harder to find the start of the next one; shorter lines break the rhythm of reading. The size grows a little on wide screens and the line spacing stays generous, so a long piece can be read without strain.

The opening letter is drawn as a small grid of cells in the growth-ring colours of the homepage name. It is the only decoration inside the reading column, and it does not move.

Note On wide screens, notes sit in the margin beside the paragraph they belong to. On a phone they fold into the text, set apart by a rule.

Notes like the one beside this paragraph keep asides out of the main line of thought. The strip of cells along the top of the window fills as you scroll, so you always know how much is left.

A section heading

Headings use the label face so they stand out from the text without shouting. Links in the text are underlined in the link colour, and change colour when you point at them.

A quotation sits between a column of small squares and the text, larger and in italics, so it reads as a pause.

Code and data appear in a block with a slightly darker ground and a fixed-width face:

cells grown per frame = all cells × time since last frame ÷ 2200 ms

The page ends with the date, a way to get in touch, and links onward. Nothing here asks for attention it has not earned.
